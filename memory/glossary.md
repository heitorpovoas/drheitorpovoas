# Glossário

Termos, siglas e convenções recorrentes no trabalho do Dr. Heitor Póvoas.

## Registros e regulatório

| Termo | Significado |
|---|---|
| **CRM-BA 11.157** | Registro no Conselho Regional de Medicina da Bahia |
| **RQE 23086** | Registro de Qualificação de Especialista — Cirurgia Bariátrica ⚠️ *não é 2308* |
| **RQE 9689** | RQE — Medicina Intensiva (AMIB) |
| **RQE 4384** | RQE — Cirurgia Geral |
| **CREMEB** | Conselho Regional de Medicina do Estado da Bahia |
| **CFM 2.336/2023** | Resolução de publicidade médica — disclaimer obrigatório nas publicações |
| **CFM 2.333/2023** | Veda terapia hormonal com fim estético, de ganho muscular ou de desempenho |

## Composição corporal

| Termo | Significado |
|---|---|
| **BIA** | Bioimpedância — mede impedância elétrica, estima os demais compartimentos |
| **ACT** | Água Corporal Total |
| **AIC / AEC** | Água intracelular / água extracelular |
| **AEC/ACT** | Razão que denuncia mudança de hidratação entre exames — marcador-chave |
| **MLG** | Massa Livre de Gordura (= massa magra) |
| **SMM** | Skeletal Muscle Mass — massa muscular esquelética |
| **LBM** | Lean Body Mass — massa magra |
| **PGC** | Percentual de Gordura Corporal |
| **DXA** | Densitometria — mede massa magra e gordura, não separa músculo |
| **Constante de Pace-Rathbun** | ~73% — fração de água assumida na massa magra por todo algoritmo de BIA |

## Farmacologia metabólica

| Termo | Significado |
|---|---|
| **GLP-1** | Agonista do receptor de GLP-1 (semaglutida, liraglutida) |
| **GIP/GLP-1** | Agonista duplo — tirzepatida |
| **TRT** | Terapia de reposição de testosterona |
| **ADAM** | Androgen Deficiency in the Aging Male — questionário de triagem, baixa especificidade |
| **SURMOUNT / SURPASS** | Programas de fase 3 da tirzepatida (obesidade / diabetes) |
| **STEP / SELECT** | Ensaios pivotais da semaglutida |
| **T4DM** | Ensaio de testosterona para prevenção de DM2 |
| **IMAT** | Tecido adiposo intramuscular |
